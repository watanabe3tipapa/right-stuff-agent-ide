# 既知の制約

現時点でできないことと、その理由をまとめます。できることの一覧は
[FEATURES.md](./FEATURES.md) を参照してください。

## プラットフォームと配布

- macOS 専用です（macOS 11 以降）。Windows / Linux 版は提供しません。Agent Desktop が macOS の Accessibility API とウィンドウ操作に依存しているためです
- 配布用 DMG は Developer ID 署名・公証を受けていません（arm64 は ad-hoc 署名、x64 は未署名）。初回起動時に警告が出た場合は、アプリを右クリック →「開く」を選択してください
- 自動更新はありません。新しい版は GitHub Releases から入手してください
- 起動時はプライマリモニタの中央へ配置し、画面外に復元された場合はタイトルバーが見える位置へ補正します（v0.3.8 以降）

## 外部ツール

- `agent-desktop` CLI は同梱していません。別途インストールするか、`AGENT_DESKTOP_BIN` でパスを指定してください
- 言語サーバーとデバッグアダプターは同梱していません。使う言語に応じて別途インストールしてください。導入例は [DEVELOPMENT.md](./DEVELOPMENT.md) にあります
- Git パネルと Git スキルはローカルの `git` CLI を利用します。`git` がインストールされていない場合はエラーを表示します
- Openship の履歴・ログ・ロールバックはセルフホスト REST API 経由です。CLI のみで使用する場合は Base URL と PAT を設定しないと履歴系は使えません。CLI のデプロイは設定した Project ID / Branch を明示的に渡します

## エージェントと LLM

- LLM は OpenAI 互換 API のみ対応します。Tauri 版では設定画面から接続できますが、ブラウザデモでは利用できません。Anthropic 固有 API は未対応です
- 計画の実行対象は Agent Desktop の許可アクションと、マニフェストで宣言したスキルに限られます。スキルから実行できる操作は、エディタ・Git・許可プログラム・DAP の固定ハンドラのみです
- ターミナルスキルは許可リストのプログラムだけを実行し、PTY への直接入力や任意のシェル文字列は扱いません
- 実行中の停止（`skill_cancel`）はターミナルスキルと検証チェックが対象です。エディタ・Git・デバッグの同期ハンドラは途中停止できません
- 計画と実行結果はメモリ上にのみ保持され、再起動すると失われます。変更操作は計画承認後も、実行時に OS のネイティブ承認ダイアログで確認します（ポリシーで「許可」にすることはできません）
- スナップショットは取得前に毎回ネイティブ確認を表示します。取得した内容はメモリ上にのみ保持し、再起動すると失われます。機密ウィンドウの自動マスクは未実装で、画面に映ったメール・銀行・パスワード管理などの情報はそのまま含まれます

## エディタと IDE 機能

- LSP は補完・定義ジャンプ・ホバー・診断・名前変更・参照検索・コードアクション・ワークスペースシンボル検索に対応します。シグネチャヘルプ、セマンティックトークン、フォーマット、ファイルの作成・削除を伴うリファクタリングは未対応です
- DAP は起動・停止・ステップ実行・ブレークポイント・変数表示のみで、attach と条件付きブレークポイントは未対応です。デバッグは `lldb-dap` と `debugpy` のみに対応します
- Git パネルはステージ・コミット・差分・履歴に対応します。マージ・リベース・プッシュなどの履歴操作は未対応です
- 検証ループは `package.json`（npm / pnpm / yarn）と `Cargo.toml` を持つワークスペースだけを対象にします。検証コマンドは `npm run typecheck` などの固定の組み合わせで、任意のコマンドは実行しません
- 統合ターミナルは Tauri 版でのみ利用できます。PTY はアプリ終了時に停止します。シェルは `RIGHT_STUFF_SHELL` または `SHELL` で変更でき、絶対パスで存在する実行ファイルのみ起動します
- macOS の Dock メニュー「終了」、ログアウト、再起動による終了は OS が直接アプリを終了するため、未保存確認の対象外です（`⌘Q` とアプリメニューの「終了」は確認します）
- IDE 機能（LSP / DAP / Git / ターミナル）は搭載済みですが、今後も継続的に高めていく段階です

## ブラウザデモ

- ブラウザデモでは LLM・Git・ターミナル・OS 操作は動作しません。エディタ、Markdown プレビュー、履歴、スキルポリシー、PWA を試せます
- デモの変更はそのブラウザの localStorage に保存され、サーバーへは送信しません。localStorage が使えない環境では再読み込みで失われます。デモバーの「初期状態に戻す」で削除できます
- オフラインで使えるのは、一度読み込んだブラウザデモの静的アセットだけです

## データと運用

- 監査ログはローカルの SQLite に保存され、保持期間の既定は 30 日、上限は 5,000 件です。監査ログを無効にしても既存の記録は残ります。コマンド引数・出力・エラーの抜粋を含むため、共有する場合は注意してください
- 同期・共同編集は提供していません
- アプリ本体は Web 配信しません。配布は GitHub Releases の DMG とソースからのビルドです
