# 日本語表記の用語集

Right-Stuff Agent IDE のドキュメントとテンプレートで使う日本語表記をまとめます。
この表は `npm run glossary` が読み取り、`README.md`、`docs/**/*.md`、
`templates/**/*.md` に非推奨の表記があれば CI を失敗させます。

| 推奨表記 | 非推奨 | 備考 |
| --- | --- | --- |
| サーバー | サーバ | 末尾の長音を省略しない |
| ユーザー | ユーザ | 末尾の長音を省略しない |
| インターフェース | インターフェイス | ソフトウェアの境界を指す場合 |
| リポジトリ | レポジトリ | Git の用語 |
| デフォルト | ディフォルト | 既定値 |
| ライブラリ | ライブラリー | パッケージや共通コード |
| コンパイラー | コンパイラ | 末尾の長音を省略しない |

## 表記ルール

- 全角の英数字は使いません。コード、URL、識別子は半角にします。
- 半角カタカナは使いません。コードブロックとインラインコードの外側は全角にします。
- 行頭に `、` `。` `）` `」` などの閉じ括弧・句読点を置きません。
- 行末に `（` `「` などの開き括弧を置きません。
- `。。` `、、` のように句読点を連続させません。
- コードブロック、インラインコード、frontmatter、URL だけの行は検査対象外です。
- 迷った場合は、この表の「推奨表記」を優先します。

## 表記の例外

- 引用や原文の再現など、意図して非推奨表記を使う場合は、行末に
  `<!-- glossary: allow -->` を置きます。
- 製品名、API 名、ファイル名、コマンド名は変更しません。
- `サーバ` や `ユーザ` が別の語の一部になっている場合は、この表の対象外です。
