サンプルが目指す構成

Tauri 版の設計を紹介するためのサンプルです。Phase 0 で実装済みの範囲は README を参照してください。

✎
執筆体験の継承
Monaco による Markdown / コード編集、タブ、未保存管理。ワークスペース管理と SQLite のバージョン履歴を Phase 0 から実装。
◆
エージェントによる直接操作
Agent Desktop の OS アクセシビリティツリー API を統合し、エディタ UI と外部アプリの両方をエージェントが操作できる構成を目指します（Phase 1）。
⚙
本格的 IDE 機能
Monaco Editor を中心に、LSP クライアント、Git 統合、統合ターミナル、デバッガ連携を Phase 2 以降で追加します。
🔒
安全な承認フロー
危険な操作（ファイル削除、Git push、ターミナル実行）の承認フローを Phase 1 で実装します。機密ウィンドウの自動マスクも計画しています。
🔄
検証ループ
エージェントのアクション後にスナップショットを再取得し、状態変化を検証する設計です。Phase 1 で接続します。
🌐
マルチプラットフォーム
まずは macOS に対応。Windows / Linux は Agent Desktop の対応状況を見て検討します。
Evaluation

特徴・良い点・注意点

サンプル公開時点の率直な評価です。機能の全体像は上の「サンプルが目指す構成」に、実装済みの範囲は README にまとめています。

良い点

  • Tauri 2.0 のネイティブアプリ — Electron より軽量で、macOS のウィンドウと統合しやすい
  • ファイルが主役 — ワークスペースの Markdown を直接編集。Finder や Git とそのまま併用できる
  • 書き味を重視 — Monaco、タブ、未保存管理、GFM の分割プレビュー
  • 履歴と安全性 — 保存ごとの SQLite 履歴、atomic write、ゴミ箱へのソフトデリート、パス検証
  • 操作が見える — エージェントのコマンド、stdout / stderr、終了コードを UI に表示
  • MIT の参考実装 — 自分の IDE を作るための出発点として利用できる

注意点

  • LLM は未接続 — チャットは /status と /snapshot のみ。計画立案と承認フローは Phase 1
  • Agent Desktop が別途必要 — CLI は同梱していない。PATH か AGENT_DESKTOP_BIN で指定する
  • 承認フローは未実装 — 現在はアクション名の許可リストのみで、引数の検証はこれから
  • macOS のみ検証 — 配布署名・公証は未対応。Windows / Linux は未検証
  • デモは永続化しない — /app/ の変更はメモリ上のみ。再読み込みでリセット
  • 開発途上のセキュリティ設定 — CSP は開発用の null。API キー保存は Phase 1

Agent Modes

3 段階のエージェントモード

用途に応じてモードを切り替える権限設計です。実際の自律実行と承認フローは Phase 1 で実装します。

Passive
受動的支援
読み取り専用。チャット入力とエージェントによる UI 操作は無効です。
Assistive
能動的支援
チャット応答とファイル編集を支援します。危険な操作の承認フローは Phase 1 で追加します。
Autonomous
自律実行
複数ステップの自律実行を想定したモードです。現在は許可されたアクションのみ実行し、承認フローは Phase 1 で追加します。

About this sample

このサイトについて

Vercel の LP とブラウザデモは、Tauri 版が公開できるまでのサンプルです。製品版の開発は Tauri 2.0 のネイティブアプリが中心です。

Tauri 版をソースからビルドする

npm ci
npm run tauri build
open "src-tauri/target/release/bundle/macos/Right-Stuff Agent IDE.app"

ブラウザデモは /app/ で確認できます。データはメモリ上のみで、保存されません。
Agent Desktop CLI は同梱していません。別途インストールし、必要に応じて AGENT_DESKTOP_BIN を指定してください。

FAQ

よくある質問

このサイトは製品版ですか？
いいえ。Tauri 版が公開できるまでのサンプルです。開発の主力は Tauri 2.0 のネイティブアプリで、この LP とブラウザデモは構成と UI の参考実装として公開しています。
ブラウザデモの変更は保存されますか？
保存されません。デモは src/lib/demo.ts のインメモリ・ワークスペースで動作し、ページを再読み込みすると初期状態に戻ります。
どの機能が実装済みですか？
Phase 0 として、ワークスペース、Monaco エディタ、GFM プレビュー、SQLite のバージョン履歴、Agent Desktop ブリッジ、コマンドパレットが動作します。詳細は README の「既知の制約とロードマップ」を参照してください。
Agent Desktop は同梱されていますか？
同梱していません。Agent Desktop CLI を別途インストールし、PATH に通すか AGENT_DESKTOP_BIN で指定してください。
LLM を使った操作はできますか？
現在は /status と /snapshot のみ応答します。LLM プロバイダーの接続、計画立案、承認フローは Phase 1 で追加します。
自作 IDE の参考にできますか？
はい。MIT ライセンスで公開しています。Tauri コマンド、パス検証、SQLite 履歴、Monaco と Zustand の構成を、自分の IDE の出発点として利用できます。
