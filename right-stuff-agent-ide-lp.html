About

製品ではなく、
自分用の道具です。

これは、自分がコードを書き、エージェントに作業を任せ、その結果を実機で確かめるために作っている macOS アプリです。エディタとエージェントが別々の画面にあると、書いた仕様を渡し、実行結果を確認し、また戻って直す。その往復が増えていきます。このアプリは、その往復を同じワークスペースにまとめる試みです。

商用製品のようなサポートや完成度はありません。テストが足りないところも、設計を変えたいところもあります。それでも、自分自身にとって使い勝手がよいことを優先して、少しずつ直しています。合わないところはフォークして、自分の道具にしてください。

これは製品ではなく、自分が使うための道具です。ブラウザとアプリを行き来し、ボタンを押し、ログを確認する。その往復をなくしたくて作りました。

— 作者より

正直なところ

  • macOS 専用です。macOS 11 以降の Apple Silicon / Intel に対応し、Windows / Linux 版はありません。
  • DMG は Apple Developer ID の署名・公証を受けていません。初回起動時に警告が出た場合は、右クリック →「開く」で起動してください。
  • LLM は OpenAI 互換 API のみ。Anthropic 固有 API は未対応です。API キーは OS キーチェーンに保存します。
  • Agent Desktop は別途インストール。OS 操作を使う場合だけ必要です。同梱していません。
  • 自動更新はありません。新しい版は GitHub Releases から手動で入手してください。
  • 共同編集・クラウド同期はありません。その代わり、原稿と履歴は端末内に残ります。

Three minutes

3 分でわかる、このアプリの使い方。

「書く」「任せる」「確かめる」の 3 つが、1 つの画面に収まっています。LLM と Agent Desktop を使う機能は Tauri 版のみです。

01 / WRITE

書く

フォルダを開き、Monaco で Markdown やコードを編集します。原稿はアプリのデータベースではなく、選んだフォルダのファイルに直接保存します。

  • タブ・未保存表示・⌘S / ⌘⇧S
  • GFM の分割プレビュー
  • 保存ごとのローカル履歴（100 版 / ファイル）
02 / DELEGATE

任せる

Chat で相談し、Plan で意図を実行計画に変えます。計画は許可された操作だけで組み立てられ、承認するまで実行されません。

  • OpenAI 互換 API のストリーミングチャット
  • 計画単位の承認と手順ごとの実行
  • スキル実行（エディタ / Git / ターミナル / デバッグ）
03 / VERIFY

確かめる

変更後は typecheck / lint / test を実行し、必要なら実機の画面をアクセシビリティツリーで読み取ります。結果は監査ログと HTML レポートに残ります。

  • 検証ループと実行の停止
  • Agent Desktop による実機の確認・操作
  • 自己完結 HTML レポート

What works today

いま、実際にできること。

未実装のものは「これから」に分けています。ここには、いま動作する機能だけを書いています。

WORKSPACE

フォルダをそのまま開く

配下のファイルを再帰的に表示し、作成・名前変更・削除・再読み込みに対応します。前回のワークスペースは次回起動時に復元されます。

EDITOR

書くためのエディタ

Monaco によるシンタックスハイライト、タブ、未保存インジケーター、一括保存。Markdown は GFM の分割プレビューで確認できます。

HISTORY

保存ごとの履歴

保存のたびに SQLite へ記録し、ファイルごとに最新 100 版を保持します。過去の版をプレビューして、エディタへ復元できます。

CHAT / PLAN

相談して、計画する

OpenAI 互換 API に接続し、ストリーミングで相談できます。意図を入力すると、許可された操作だけを使った実行計画を生成します。

LLM は Tauri 版
APPROVAL

承認するまで動かない

計画は単位ごとに承認し、変更操作は実行のたびに macOS のネイティブ承認ダイアログで確認します。ポリシーで「許可」にすることはできません。

AGENT DESKTOP

実機の画面を読む・操作する

アクセシビリティツリーでボタン名や有効 / 無効状態を読み取り、クリック・入力・値の設定を行います。スクリーンショットだけでは分かりにくい、文言の抜けや状態の不整合を確認できます。

CLI を別途インストール
SKILLS

宣言した操作だけを実行

v1 マニフェストで宣言したエディタ・Git・ターミナル・デバッグの操作を、Rust の固定ハンドラで実行します。任意のシェル文字列は受け取りません。

VERIFY

変更後に検証する

package.json や Cargo.toml から typecheck / lint / test を解決して実行し、結果を Skills タブに表示します。実行中の停止にも対応しています。

IDE

日常の IDE 機能

クイックオープン、Git パネル、統合ターミナル (PTY)、LSP の補完・定義ジャンプ・診断・名前変更、DAP のブレークポイントと変数表示を備えます。

AUDIT

操作をローカルに記録

計画の作成・承認・却下、実行・拒否・停止、ポリシー変更、デプロイを SQLite に記録します。監査ログは既定で 30 日、最新 5,000 件を保持します。

REPORT

結果を 1 枚の HTML に

承認 → 実行 → 検証 → 結果の流れ、パラメータ、変更ファイル、標準出力をまとめた自己完結 HTML を生成します。外部 CDN は使いません。

DEPLOY

作ったものを届ける

Openship の CLI を優先し、未検出のときだけセルフホスト REST にフォールバックします。デプロイとロールバックは承認を通り、履歴とログを確認できます。

Safety

何を許して、何を止めるか。

エージェントに OS を操作させる以上、権限の設計を曖昧にしたくありません。実装している制約を、そのまま書きます。

エージェント / スキルが実行する操作の扱い
種類例既定の扱い
読み取り 画面のスナップショット、ウィンドウ一覧、Git の状態 許可（ポリシーで確認 / 禁止に変更可）
変更 クリック、入力、値の設定、スキルによるファイル書き込み、コミット、デプロイ 実行のたびにネイティブ承認
禁止 許可リスト外の操作、ワークスペース外のパス、任意のシェル文字列 Rust 側で拒否

配布物について

DMG は Apple Developer ID の署名・公証を受けていません（arm64 は ad-hoc 署名、x64 は未署名）。初回起動時に Gatekeeper の警告が出た場合は、アプリを右クリック →「開く」を選択してください。

Intel x64 版（v0.3.8）は、Intel Core i7 / macOS 15.8.3 の実機で SHA-256 を照合し、インストールと起動を確認しています。署名・公証は先送りにしています。

自動更新はありません。新しい版は GitHub Releases から手動で入手してください。

データの保存場所
データ保存先外部送信
原稿・コード選んだフォルダのファイルなし
バージョン履歴・設定・監査ログ端末内の SQLite（WAL）なし
API キー・Openship PATOS キーチェーンなし
画面スナップショットメモリ上のみ（再起動で消える）なし
ブラウザデモの編集内容このブラウザの localStorageなし

補足: ファイル操作は絶対パス・..・ワークスペース外への書き込みを拒否します。シンボリックリンクはツリーに列挙しません。書き込みは一時ファイル + rename、削除はワークスペース内のゴミ箱へ退避します。Git 操作とターミナルスキルはシェル文字列を組み立てません。LSP / DAP は固定レジストリの実行ファイルだけを起動します。CSP は Tauri と Vercel の両方に設定しています。

Agent modes

自律性は、段階的に。

モードは「どこまで任せるか」の切り替えです。どのモードでも、変更操作のネイティブ承認は省略できません。

Passive

見るだけ

読み取り専用。チャット入力とエージェントによる操作は無効です。実装の確認や、誤操作を避けたいときに使います。

Assistive

手順ごとに任せる

チャットとファイル編集が使えます。計画は手順ごとに実行し、変更操作のたびに承認ダイアログを表示します。

Autonomous

承認済みの計画を連続実行

承認した計画を複数ステップで実行します。失敗した時点で停止し、変更操作には実行のたびに承認ダイアログを表示します。

Use cases

こんなことに使っています。

実装済みの操作だけで構成した例です。すべての操作が、承認と監査ログを通ります。

SMOKE TEST

リリース前の実機確認

launch でアプリを起動し、list-windows / focus-window で対象を選び、snapshot でメニューや初期状態を確認します。最後に close-app で後片付けします。

COPY CHECK

UI 文言とローカライズの確認

アクセシビリティツリーからボタン名・ラベル・有効 / 無効状態を読み取ります。画面の見た目だけでは拾いにくい、文言の抜けや不整合を確認できます。

EDIT & VERIFY

編集 → 検証 → レポート

エディタで修正し、Skills タブの検証ループを通してから、結果を HTML レポートに保存します。何を変えて、何を確認したかを 1 枚に残せます。

SHIP

修正をそのまま届ける

検証が通ったら Deploy タブから承認付きでデプロイします。履歴・ログ・ロールバックも同じ画面で扱えます。CLI がなければセルフホスト REST に切り替わります。

Getting started

はじめ方。

まずブラウザで触り、必要なら DMG を入れてください。LLM と OS 操作は、インストール後の Tauri 版で有効になります。

STEP 01

ブラウザで触る

インストール不要です。デモ用のワークスペースが開き、編集内容はこのブラウザの localStorage に保存されます。「初期状態に戻す」ボタンでいつでもリセットできます。

→ /app/ を開く
# LLM・Git・ターミナル・OS 操作は動きません
STEP 02

DMG を入れる

GitHub Releases から Apple Silicon / Intel の DMG を入手します。未署名のため、初回は右クリック →「開く」で起動してください。対応 OS は macOS 11 以降です。

→ releases/latest
# v0.3.8 / aarch64 または x64
STEP 03

フォルダを開く

起動後、サイドバーから作業したいフォルダを選びます。前回のフォルダは次回起動時に復元されます。原稿はそのフォルダのファイルとして保存されます。

→ フォルダを開く
# 保存: ⌘S / 全保存: ⌘⇧S
# コマンドパレット: ⌘K
STEP 04

LLM と Agent Desktop を設定する

LLM はエージェントパネル右上の歯車から、OpenAI 互換 API を設定します。OS 操作を使う場合だけ、Agent Desktop CLI を別途インストールし、macOS のアクセシビリティ権限を付与します。

→ npm install -g agent-desktop
# PATH にない場合:
→ AGENT_DESKTOP_BIN=/path/to/bin
ソースからビルドする場合

Node.js ^20.19.0 || >=22.12.0、Rust 1.88 以上、Xcode Command Line Tools が必要です。

$ git clone https://github.com/watanabe3tipapa/right-stuff-agent-ide.git
$ cd right-stuff-agent-ide
$ npm ci
$ npm run tauri dev

配布用にビルドする場合は npm run tauri build を実行します。生成物は src-tauri/target/release/bundle/ に出力されます。

Limitations & next

できないことと、これから。

「できる」と書いた範囲は動作します。それ以外は、まだできません。ロードマップは約束ではなく、優先順位のメモです。

いま、できないこと

  • Windows / Linux 版はありません。macOS 11 以降の Apple Silicon / Intel のみです。
  • LLM は OpenAI 互換 API のみ。Anthropic 固有 API、画像生成、音声入力は未対応です。
  • DAP は attach と条件付きブレークポイントが未対応。起動・停止・ステップ実行・ブレークポイント・変数表示までです。
  • LSP はシグネチャヘルプ、セマンティックトークン、フォーマット、ファイル作成 / 削除を伴うリファクタリングが未対応。補完・定義・ホバー・診断・名前変更・参照検索・コードアクションまでです。
  • Git はマージ・リベース・プッシュが未対応。状態・差分・ステージ・コミット・履歴までです。
  • 計画とスナップショットは再起動で消えます。監査ログとレポートは残ります。
  • 共同編集・クラウド同期・自動更新はありません。
  • DMG は Apple Developer ID の署名・公証を受けていません。Gatekeeper の警告が出ます。

次にやること

  • Anthropic API への対応 — 現在は OpenAI 互換 API のみです。
  • DAP の attach と条件付きブレークポイント — 実機プロセスへの接続を試したい。
  • 署名と公証 — Gatekeeper の警告をなくす。先送り中です。
  • 自動更新 — 手動ダウンロードの負担を減らす。
  • テストと UI の磨き込み — 個人開発の範囲で、壊れにくさを優先します。
  • ドキュメントの拡充 — 使い方と設計判断を、実装と同じ速さで更新します。

FAQ

よくある質問。

これは製品ですか？

いいえ。個人が自分用に作っている Hobby project で、Early Access の位置付けです。商用サポートや SLA はありません。動く範囲は公開していますが、完成品として提供しているものではありません。

Cursor や他の AI エディタと何が違いますか？

コード編集の支援だけではなく、macOS の実機アプリをアクセシビリティツリー経由で確認・操作する点に重きを置いています。操作は許可リストと承認を通り、結果はローカルの監査ログと HTML レポートに残ります。MIT なので、自分のワークフローに合わせてフォークできます。一方で、完成度・サポート・対応 OS では及びません。

ブラウザデモの変更は保存されますか？

保存されます。デモのワークスペース、編集履歴、スキルポリシーは、このブラウザの localStorage に保存されます。サーバーには送信しません。デモバナーの「初期状態に戻す」から、いつでも削除できます。localStorage が使えない環境では、変更はページの再読み込みで失われます。

LLM は使えますか？

Tauri 版では、OpenAI / Ollama / LM Studio / OpenRouter などの OpenAI 互換 API に接続できます。ストリーミング表示、生成停止、接続テストに対応し、API キーは OS キーチェーンに保存します。ブラウザデモでは LLM を利用できません。Anthropic 固有 API は未対応です。

Agent Desktop は必要ですか？

OS 操作を使う場合だけ必要です。アプリには同梱していません。Agent Desktop（Apache-2.0）を npm install -g agent-desktop で別途インストールし、PATH に通すか AGENT_DESKTOP_BIN で指定してください。macOS では agent-desktop permissions --guide でアクセシビリティ権限を付与します。エディタとスキル実行は、Agent Desktop なしでも使えます。

Intel Mac でも使えますか？

使えます。macOS 11 以降の Apple Silicon / Intel 向けに DMG を配布しています。Intel x64 版（v0.3.8）は Intel Core i7 / macOS 15.8.3 の実機で SHA-256 を照合し、インストールと起動を確認しています。Apple Silicon で x64 版を使う場合は Rosetta 2 が必要です。

DMG が未署名なのはなぜですか？

Apple Developer ID の署名・公証を先送りしているためです。初回起動時に Gatekeeper の警告が出た場合は、アプリを右クリック →「開く」で起動してください。出所を確認したい場合は、GitHub Releases の SHA-256 と照合できます。署名・公証はロードマップにありますが、時期は決めていません。

データはどこに保存されますか？

原稿とコードは、選んだフォルダのファイルに保存されます。バージョン履歴・設定・監査ログは端末内の SQLite、API キーと Openship PAT は OS キーチェーンです。アカウント、テレメトリ、クラウド同期はありません。LLM と Openship へのリクエストだけは、設定した API へ Rust から送信します。

不具合や要望はどこに送ればいいですか？

GitHub Issues へお願いします。脆弱性は公開 Issue ではなく、SECURITY.md の非公開フォームから報告してください。個人開発のため、返信や修正には時間がかかることがあります。
