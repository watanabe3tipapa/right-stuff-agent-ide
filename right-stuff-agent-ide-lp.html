Tauri 版の構成と実装

Tauri 版は GitHub Releases の DMG で配布中です。ブラウザデモは、インストールせずに UI を試すためのサンプルです。実装済みの範囲は README を参照してください。

✎
執筆体験の継承
Monaco による Markdown / コード編集、タブ、未保存管理、ワークスペース管理。SQLite のバージョン履歴を Phase 0 から実装しています。
◆
エージェントによる直接操作
Agent Desktop の OS アクセシビリティツリー API を統合し、エディタ UI と外部アプリの両方をエージェントが操作できます。許可アクションと引数の検証、計画単位の承認、ネイティブ承認ダイアログを経て実行します。
⚙
本格的 IDE 機能
Monaco Editor を中心に、クイックオープン、Git 統合、統合ターミナル (PTY)、LSP（補完・定義ジャンプ・ホバー・診断・名前変更・参照検索・コードアクション・シンボル検索）、DAP デバッグ（lldb-dap / debugpy）を実装済みです。
🔒
安全な承認フロー
LLM が生成した計画は許可アクションと引数を検証した上で承認制で実行します。変更操作は計画承認後も、実行直前に OS のネイティブ承認ダイアログで確認します。承認履歴の監査ログはローカル SQLite に記録し、機密ウィンドウの自動マスクは今後追加します。
🔄
検証ループ
エージェントのアクション後にスナップショットを再取得し、状態変化を検証する設計です。検証ループは今後実装します。
🖥
macOS ネイティブ
macOS 専用のデスクトップアプリとして、Apple Silicon / Intel の DMG を配布しています。Overlay タイトルバー、Keychain、アクセシビリティ権限など macOS の機能に統合しています。
Local-first Deploy

Openship 連携は端末内で完結

Openship CLI を優先し、未検出のときだけセルフホスト API にフォールバックします。設定・PAT・監査ログは端末の外へ出ません。

Evaluation

特徴・良い点・注意点

現在の実装を現時点で評価したものです。機能の全体像は上の「Tauri 版の構成と実装」に、実装済みの範囲は README にまとめています。

良い点

  • Tauri 2.0 のネイティブアプリ — Electron より軽量で、macOS のウィンドウと統合しやすい
  • ファイルが主役 — ワークスペースの Markdown を直接編集。Finder や Git とそのまま併用できる
  • 書き味を重視 — Monaco、タブ、未保存管理、GFM の分割プレビュー
  • 履歴と安全性 — 保存ごとの SQLite 履歴、atomic write、ゴミ箱へのソフトデリート、パス検証
  • 操作が見える — エージェントのコマンド、stdout / stderr、終了コードを UI に表示
  • MIT の参考実装 — 自分の IDE を作るための出発点として利用できる

注意点

  • LLM は OpenAI 互換 API に対応 — Tauri 版では OpenAI / Ollama / LM Studio / OpenRouter などに接続できます。ブラウザデモでは利用できません。Anthropic 固有 API は今後対応
  • Agent Desktop が別途必要 — CLI は同梱していない。PATH か環境変数 AGENT_DESKTOP_BIN で指定する
  • 計画の実行範囲は限定的 — LLM の計画立案、計画単位の承認、実行結果の監査ログは実装済みですが、実行できるのは Agent Desktop の許可アクションだけです。エディタ・Git・ターミナルのスキル実行と検証ループは今後対応
  • macOS 専用 — 対応 OS は macOS 11 以降（Apple Silicon / Intel）のみです。Windows / Linux 版は提供しません。配布用 DMG は Developer ID 署名・公証なしで、Intel 実機での起動確認は未実施です
  • デモは永続化しない — /app/ の変更はメモリ上のみ。再読み込みでリセット
  • バイナリは Developer ID 未署名 — Apple Silicon / Intel 向け DMG を GitHub Releases で公開中。CSP とセキュリティヘッダーは Tauri / Vercel とも設定済み。API キーは OS キーチェーンに保存します。署名・公証は先送り

サンプルの動かし方

ブラウザデモで UI を確認し、Tauri 版をソースから起動して実際のファイル操作を試せます。

始める前に確認
  • 対応 OS は macOS 11 以降のみ — 本アプリは macOS 専用です。Windows / Linux 版は提供していません。
  • ブラウザデモは保存されません — 変更はメモリ上のみで、再読み込みすると初期状態に戻ります。
  • LLM は Tauri 版で利用可能 — ブラウザデモでは利用できません。エージェントパネル右上の歯車アイコンから設定します。
  • Agent Desktop CLI は別途必要 — 同梱していません。次の手順でインストールします。
01

Agent Modes

3 段階のエージェントモード

用途に応じてモードを切り替える権限設計です。計画は LLM が生成し、承認するまで実行されません。

Passive / 受動
受動的支援
読み取り専用。チャット入力とエージェントによる UI 操作は無効です。
Assistive / 支援
能動的支援
チャット応答とファイル編集を支援します。計画は手順ごとに実行し、Agent Desktop の変更操作はネイティブ承認ダイアログを経由します。
Autonomous / 自律
自律実行
承認した計画を複数ステップで連続実行します。失敗した時点で停止し、変更操作には実行のたびにネイティブ承認ダイアログを表示します。

About this sample

このサイトについて

Vercel の LP とブラウザデモは、インストールせずに UI を試すためのサンプルです。製品版は GitHub Releases の DMG で配布しています。

対応 OS: macOS 11 以降（Apple Silicon / Intel）のみ。Windows / Linux 版は提供していません。

配布版: GitHub Releases の DMG（Apple Silicon / Intel）。未署名・未公証のため、初回起動時に警告が出た場合は右クリック →「開く」を選択してください。

ソースからビルドする場合

npm ci
npm run tauri build
open "src-tauri/target/release/bundle/macos/Right-Stuff Agent IDE.app"

Agent Desktop CLI（OS 操作を使う場合）

npm install -g agent-desktop
agent-desktop version
agent-desktop permissions --guide

ブラウザデモは /app/ で確認できます。データはメモリ上のみで、再読み込みすると失われます。

プライバシー: この LP とブラウザデモは、入力内容をサーバーへ送信しません。アカウント登録・テレメトリ・クラウド同期もありません。Tauri 版の原稿は、選んだフォルダのファイルとして端末内に保存されます。

FAQ

よくある質問

このサイトは製品版ですか？
このページは Web 上で UI を試すためのサンプルです。製品版は macOS 専用の Tauri アプリで、GitHub Releases の DMG からインストールできます。
ブラウザデモの変更は保存されますか？
保存されません。デモは src/lib/demo.ts のインメモリ・ワークスペースで動作し、ページを再読み込みすると初期状態に戻ります。
どの機能が実装済みですか？
Phase 0 として、ワークスペース、Monaco エディタ、GFM プレビュー、SQLite のバージョン履歴、Agent Desktop ブリッジ、コマンドパレットが動作します。Phase 1 では、OpenAI 互換 LLM への接続、ストリーミングチャット、生成停止、接続テスト、API キーの OS キーチェーン保存、計画立案と計画単位の承認フロー、エージェントポリシー、監査ログを追加しました。v0.2.0 ではローカルファーストの Openship 連携（Deploy タブ、CLI / REST、履歴・ログ・ロールバック）を追加。v0.3.0 ではクイックオープン、Git パネル、統合ターミナル (PTY) を追加し、編集・確認・実行を同じワークスペースで完結できるようにしました。v0.3.1 では LSP（補完・定義ジャンプ・ホバー・診断）と DAP（lldb-dap / debugpy によるデバッグ）を、v0.3.3 では LSP の名前変更・参照検索・コードアクション・ワークスペースシンボル検索を、v0.3.4 では人間向けのスキルライブラリとショーケース別窓を、v0.3.5 ではスキル実行後の検証ループ（typecheck / lint / test）を、v0.3.6 では Git・ターミナル・デバッグのスキルハンドラを、v0.3.7 ではスキル実行レポートの HTML レンダラーを追加しました。詳細は README の「次の候補」と「制約」を参照してください。
Agent Desktop は同梱されていますか？
同梱していません。Agent Desktop（Apache-2.0）を npm install -g agent-desktop で別途インストールし、PATH に通すか環境変数 AGENT_DESKTOP_BIN で指定してください。macOS では agent-desktop permissions --guide でアクセシビリティ権限を付与します。バージョン固定の要件はありません。
入力内容はサーバーに送信されますか？
送信されません。この LP とブラウザデモは静的サイトで、アカウント登録・テレメトリ・クラウド同期はありません。デモの編集内容はブラウザのメモリ上にのみ保持され、再読み込みすると失われます。Tauri 版の原稿も、選んだフォルダのファイルとして端末内に保存されます。
LLM を使った操作はできますか？
はい。Tauri 版では、エージェントパネル右上の歯車アイコンから OpenAI 互換 API（OpenAI / Ollama / LM Studio / OpenRouter / カスタム）に接続できます。API キーは OS キーチェーンに保存され、チャットはストリーミング表示・生成停止・接続テストに対応しています。Plan タブまたは /plan に意図を入力すると、LLM が許可アクションだけを使った実行計画を作成し、承認後に実行できます。ブラウザデモでは LLM を利用できません。
自作 IDE の参考にできますか？
はい。MIT ライセンスで公開しています。Tauri コマンド、パス検証、SQLite 履歴、Monaco と Zustand の構成を、自分の IDE の出発点として利用できます。
